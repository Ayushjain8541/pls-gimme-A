# Real-paper verification

No course paper or official key was supplied for live validation during implementation. Synthetic extraction and provider-isolated workflow tests cannot establish real-paper fidelity.

With a representative question paper, its reference key, and configured model credentials:

- Run the explicit `verify:paper` command from README, or upload through the module UI.
- Compare every original question number and leaf subpart with the converted paper. Check page-spanning prompts and shared parent instructions.
- Verify all options, equations, code, tables and figures. Open original question pages to compare.
- Check each answer mapping and source reference. Confirm external AI solution labels remain provisional.
- Submit independently checked correct, partly correct and incorrect responses, including a distractor that reflects a recognizable misconception.
- Confirm the explanation follows the supplied key and written feedback quotes the actual response. Inspect any marks against the rubric.
- Try a drawing question, an ordinary skip, a refresh during assessment, and a resumed session. Check completion and exclusions.
- Upload a mixed-text/scanned paper, an ambiguous key and a missing-solution paper. Confirm visible preparation/repair states rather than fabricated success.
- Record observed defects below without committing course paper content, private answers, API credentials or local absolute source paths.
